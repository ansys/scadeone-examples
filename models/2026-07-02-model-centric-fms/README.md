## A Model-Centric Flight Management System Architecture

This model is a companion to the *Swan in practice* article series, starting with
[A Model-Centric Flight Management System Architecture](https://innovation.ansys.com/public/articles/topic/a-model-centric-flight-management-system-architecture-expu/).

It implements a simplified Flight Management System (FMS) User Application in Swan:

- an ARINC 424-like navigation database decoder,
- an airport and runway database,
- an ARINC 661 runtime protocol encoder and decoder,
- the User Application logic driving an ARINC 661 Cockpit Display System,
- UDP and file I/O through imported C operators.

> [!WARNING]
> This is an educational example. It is not a certified FMS, and the navigation data
> must not be used for real-world navigation.

## Requirements

- Ansys Scade One 2027 R1
- Ansys SCADE Solutions for ARINC 661 (any recent release), to build the Definition File
  and run the ARINC 661 server
- Windows (the UDP library relies on WinSock2)

## Content

| Folder | Content |
|---|---|
| `scade-one/FMS_App` | Main project: User Application, simulation harness `TEST_MAP::harness_send_message` |
| `scade-one/FMS` | Airport and runway database |
| `scade-one/A424` | ARINC 424-like record decoder |
| `scade-one/A661` | ARINC 661 runtime protocol (encoding and decoding), with tests |
| `scade-one/UDP` | UDP sockets (imported operators, WinSock2), with test |
| `scade-one/File` | File reading (imported operators) |
| `scade-one/Strings` | Fixed-size string library |
| `scade-a661` | ARINC 661 User Application Definition File sources and scripts |
| `data` | Navigation database `f-424` and the script that generates it |

Project dependencies:

```
FMS_App ──> A661 ──> Strings
        ──> FMS ───> A424 ──> Strings
        ──> UDP
        ──> File
```

## Instructions

1. Build the ARINC 661 Definition File (DF).
   - Run `.\scade-a661\build_df.bat [ANSYS_INSTALL_DIR]`
     (default: `%ProgramFiles%\ANSYS Inc\v261`).
   - This generates `.\scade-a661\DF\UA_1.bin`.

2. Start the ARINC 661 server.
   - Run `.\scade-a661\start_a661_server.bat [ANSYS_INSTALL_DIR]`.
   - The server window opens and listens for the User Application on UDP port 1231.

3. Tell the model where the navigation database is.
   - Set the environment variable `FMS_DATA_DIR` to the absolute path of the `data`
     folder, then start Scade One from that environment. For example:

     ```bat
     set FMS_DATA_DIR=C:\path\to\2026-07-02-model-centric-fms\data
     ```

   - If `FMS_DATA_DIR` is not set, the file `f-424` is searched in the current
     directory of the simulation.

4. In **Scade One**, open project `.\scade-one\FMS_App\FMS_App.sproj`.
   - Run job `RunWithServer`.
   - The model loads the navigation database, then connects to the ARINC 661 server.
     Enter an ICAO airport code (for example `LFBO`) in the display, and select a runway.

### Tests

- `.\scade-one\A661\A661.sproj`: job `TestProtocol` runs the ARINC 661 encoding and decoding tests.
- `.\scade-one\UDP\UDP.sproj`: job `SimulationJob0` runs a UDP loopback test.

## Navigation data

`data/f-424` is generated by `data/generate_f424.py` from the
[OurAirports](https://ourairports.com/data/) open data, which is released into the
public domain. The committed file is kept so that results are reproducible; run the
script to regenerate it from the latest data:

```bat
cd data
python generate_f424.py
```

The output is a simplified, ARINC 424-like fixed-width text file, not a certified
ARINC 424 database.
